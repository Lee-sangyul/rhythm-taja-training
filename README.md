# 리듬타자연습

음절이 들리는 박자에 맞춰 가사를 입력하는 웹 리듬 게임입니다.
※ 위 게임은 AI를 사용하여 제작하였습니다. ※

## 실행 방법

저장소의 `index.html`을 내려받아 Chrome에서 여세요. 별도 설치 없이 실행할 수 있습니다.

- **싱크 시작** — 데모 멜로디에 맞춰 초록색 글자를 입력하세요. 기준 타이밍에서 ±150ms 이내는 `PERFECT`, 그보다 빠르거나 늦어도 ±400ms 이내면 `EARLY` 또는 `LATE`로 판정합니다. 놓친 음절은 자동으로 넘어갑니다.
- **자유 연습** — 시간 제한 없이 가사를 입력할 수 있습니다.
- **내 노래로 싱크 만들기** — 음원과 가사를 넣은 뒤, 음절이 들릴 때마다 Space 키 또는 ‘타이밍 기록’ 버튼을 눌러 시간을 기록하세요. 모든 음절을 기록하면 플레이에 적용할 수 있습니다.

음원과 가사는 현재 탭에서만 사용됩니다. 페이지를 새로고침하면 기록이 초기화됩니다.
