# 리듬타자연습

음절이 들리는 박자에 맞춰 가사를 치는 웹 리듬게임 MVP.

## 실행

Chrome에서 `index.html`을 열면 돼. 설치나 서버는 필요 없어.

- **싱크 시작** — 데모 멜로디에 맞춰 초록색 글자를 입력해. ±150ms는 PERFECT, ±400ms 이내는 EARLY 또는 LATE야. 놓친 음절은 자동으로 넘어가.
- **자유 연습** — 시간 제한 없이 가사를 입력해.
- **내 노래로 싱크 만들기** — 음원과 가사를 넣고 Space로 음절마다 타이밍을 찍어. 기록을 끝내면 플레이에 적용할 수 있어.

음원과 가사는 현재 탭에서만 사용돼. 새로고침하면 기록이 초기화돼.
