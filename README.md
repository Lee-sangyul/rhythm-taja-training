# 리듬타자연습

음절이 들리는 박자에 맞춰 가사를 입력하는 웹 리듬 게임입니다.
※ 위 게임은 AI를 사용하여 제작하였습니다. ※

## 실행 방법

저장소의 `index.html`을 내려받아 Chrome에서 여세요. 별도 설치 없이 실행할 수 있습니다.

- **싱크 시작** — 데모 멜로디에 맞춰 초록색 글자를 입력하세요. 기준 타이밍에서 ±150ms 이내는 `PERFECT`, 그보다 빠르거나 늦어도 ±400ms 이내면 `EARLY` 또는 `LATE`로 판정합니다. 놓친 음절은 자동으로 넘어갑니다.
- **자유 연습** — 시간 제한 없이 가사를 입력할 수 있습니다.
- **내 노래로 싱크 만들기** — 음원과 가사를 넣은 뒤, 음절이 들릴 때마다 Space 키 또는 ‘타이밍 기록’ 버튼을 눌러 시간을 기록하세요. 모든 음절을 기록하면 플레이에 적용할 수 있습니다.

## 곡과 싱크 가사

- **작은 별** — 프랑스 전래 선율 [Ah ! vous dirai-je, maman](https://portenotes.lacultureataporte.fr/guitare/repertoire/ah-vous-dirai-je-maman)을 브라우저에서 합성하고, 새로 쓴 한국어 가사를 음표마다 맞춘 연습곡입니다.
- **LRCLIB 검색** — 음원 파일을 먼저 선택하고, 곡 제목과 아티스트를 검색한 뒤 같은 버전의 결과를 선택하세요. 검색어는 [LRCLIB](https://lrclib.net/docs)에 전송됩니다. 재생에는 선택한 로컬 음원을 사용합니다.
- **LRC 파일** — 음원과 LRC 파일을 선택한 뒤 **LRC 적용**을 누르세요. 줄 시작 시각을 기준으로 각 음절의 타이밍을 추정합니다. 음절별로 직접 시간을 맞추려면 수동 기록을 사용하세요.

음원과 가사 데이터는 현재 탭에서 사용됩니다. 페이지를 새로고침하면 기록이 초기화됩니다.
